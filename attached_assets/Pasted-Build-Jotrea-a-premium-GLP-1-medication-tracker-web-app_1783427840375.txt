### CORE MVP FEATURES

1. ONBOARDING (3 steps):
   - Welcome screen: Jotrea logo + tagline + "Start Your Journey" button
   - Select Medication: Searchable dropdown, grouped by generic name, shows brand names and formulation tags (pill/injection)
   - Set Dose & Start Date: Dose picker (based on medication), date picker, injection site rotation reminder toggle
   - Free Trial Banner: "Start your 1-month free trial of Jotrea Premium" on final screen

2. DASHBOARD (Home Tab):
   - Hero countdown: "Next dose in X days" with circular progress ring
   - "Log Dose" big CTA button (Terracotta, pulsing animation on dose day)
   - Quick stats row: Last dose | Current dose | Streak count (fire emoji)
   - Mini weight chart (last 7 entries)
   - Upcoming schedule: Next 3 doses listed

3. DOSE LOG (Calendar Tab):
   - Monthly calendar view with colored dots (green = taken, orange = scheduled, red = missed)
   - Tap any date to see/add dose details
   - Add Dose form: Date, time, dose amount, injection site (Abdomen, Thigh, Upper Arm, Buttocks), notes
   - List view toggle showing all doses with edit/delete

4. WEIGHT TRACKER (Weight Tab):
   - Input: Weight (lbs/kg toggle) + date + optional photo placeholder
   - Recharts line chart showing trend
   - Stats cards: Total lost, Avg per week, Current BMI (auto-calculated if height entered in settings)
   - Goal weight setting with progress bar

5. MED INFO (Pharmacist Tab):
   - Shows current medication with full details
   - Expandable sections: Dosing Tips, Common Side Effects, When to Call Doctor, Storage Instructions
   - "Premium" locked sections: Drug Interaction Checker, Symptom Journal, Export Report (show gold lock icon)

6. SETTINGS:
   - Medication profile (edit dose, switch meds)
   - Notification settings: Reminder time, advance warning (1hr, 2hr, day before), push toggle
   - Units: lbs/kg, mg/mcg
   - Subscription status: Free tier badge or Premium crown badge
   - About Jotrea

7. PREMIUM PAYWALL UI (integrated throughout):
   - Free user sees: "Free Plan - 1 medication, basic tracking" badge
   - Locked features show gold crown + "Premium" tag
   - Upgrade modal: $4.99/mo or $29.99/yr (40% off), 1-month free trial highlighted
   - Features to lock behind premium: Multiple meds, side effect journal, food logging, progress photos, Apple Health sync placeholder, PDF export for doctors

### TECHNICAL STACK
- React 18 + Vite + Tailwind CSS + React Router DOM
- State: React Context + LocalStorage (no backend for MVP)
- Charts: Recharts
- Dates: date-fns
- Icons: lucide-react
- Animations: framer-motion
- PWA: vite-plugin-pwa with manifest.json, service worker, install prompt

### NAVIGATION
Bottom tab bar (5 tabs): Home, Calendar, Weight, Med Info, Settings
- Active tab: Terracotta icon + label
- Inactive: Gray icon only

### DATA MODEL (LocalStorage keys)
- jotrea_user: { name, height, units, subscription: "free"|"premium", trialEndDate }
- jotrea_medication: { id, genericName, brandName, dose, frequency, startDate, injectionSite, active }
- jotrea_doses: [{ id, date, time, doseAmount, site, notes, taken: boolean }]
- jotrea_weights: [{ id, date, weight, photoUrl }]
